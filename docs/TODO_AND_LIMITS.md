## 二、逻辑上还没做好的地方

按**严重度**排序。★ = 我认为是当前最该修的。

### 2.1 ★★★ 账本记的是标的 R，你交易的是期权

我们全程用 SPX 点数算 R。你买的是 0DTE 期权。
**同样 0.236 ATR 的移动，在不同 IV、不同剩余时间、不同行权价下，期权盈亏可以差好几倍。**
他 09:45 说「736p 涨了 50%+」——那是**期权的 50%**，标的可能只走了 0.1 ATR。

这意味着：**我们账本上的 −45.1R，和你真实账户的盈亏，不是同一件事。**
可能更差（theta 每天吃），也可能更好（大波动时 gamma 放大）。
**我们从来没有量化过这条裂缝。** 这是整个项目最大的未知。

→ 最低成本的补法：你每笔实盘记录「标的入场价 / 期权入场价 / 期权出场价」，
攒 20 笔我就能算出转换关系。**不需要期权链数据，只需要你的成交记录。**

### 2.2 ★★★ 目标与止损用了两把尺子

目标 = 下一个具名位（**日线 ATR** 刻度，固定）
止损 = 结构性（近 3–5 根 K 的极值）

夜盘 K 小 → 止损小 → 「很远的目标 + 很紧的止损 + 很长的持有时间」。
这可能就是夜盘吃掉 88% 亏损的机制。**工作流正在测**（`V15_SCALE_MISMATCH.md`）。

已知的相关事实：`V15_ENTRY_LOCATION` 里唯一有效的闸门就是「止损放远」
（z_sel +4.37，257 格里唯一越过 Bonferroni 门槛的）。这很像是在**修正刻度错配**。

### 2.3 ★★ 状态层与具名位闸门完全未验证

v15.1 的两条新规则，证据**只有 2026-07-28 一天的逐条对账**。
不是统计验证。工作流正在测（含**符号检验**：区间态里把交叉信号反过来做会不会更好，
以及**安慰剂检验**：把整条 ATR 梯平移/改等距后，"贴位"效果还在不在）。

⚠ 如果安慰剂检验通过（平移梯效果一样），那"贴具名位"测的其实是
「离任意规则网格近」这个平凡属性，闸门 ⑤ 要撤回。

### 2.4 ★★ S2 的触及计数实现很脆

现在的实现：只跟踪**离当前价最近**的那条位，位一换就 `touchN := 0` 清零。
现实里价格在两条位之间来回摆时，计数会被反复清掉。
而且"次数"本身可能是错的抽象——真正的判据是**穿透深度递减**（见 §1.4 #13）。

### 2.5 ★★ 缺 compression / squeeze 状态

Saty **每天都报**："3m SPX compression / 10m SPY compression / H(ETH) SPY compression /
H(RTH) SPX compression"（07-28 09:37 原话）。这是**多周期同时报**的，不是单周期阈值。
我们的状态层只用了「在 box 内」和「五线未排列」两个代理，**没有真正的压缩指标**。

### 2.7 ★ 没有时间离场

他 **11:37 ET 收工**（自述「aim to be done by 12pm EST」）。

而我们自己已经验证过时间结构（14:30 时 P(还能走 0.236 ATR) 只剩 49.7%，
15:30 只剩 25.9%）——**这个已验证的东西没有接进执行层。**

### 2.8 ★ 分批与仓位是固定的

我们是死板的 50% / 25% / runner。他是「scale out, leave runners」，
**触发是到达对面具名位 + 执行周期极端**，且比例随情况变。
另外我们**没有仓位管理**——每笔都是满仓 1 单位。他明显不是。

### 2.9 ★ 冷却期是根数，不是结构性的

`cooldownBars = 6` 是拍脑袋的。合理的冷却应该是结构性的
（例如"直到价格离开这条位 ≥0.1 ATR"或"直到状态切换"），不是数 K 线。

### 2.10 ★ 夜盘没有单独的最小风险距离

你明确说过不在规则层分时段——所以我没加。
但如果 §2.2 的刻度错配成立，正确的做法可能不是"分时段"，
而是**让止损也用日线 ATR 刻度**（这样夜盘自动就有更远的止损），
这不算分时段，是统一刻度。**等工作流结果。**

### 2.11 缺多周期 Phase 配对

「3m extreme / 10m has room」是他减仓与留 runner 的核心句式。
我们有 3m 和 10m 两个 Phase，**从来没有配对呈现**，更没有据此调整分批。

### 2.12 前向账本无法跨版本比较

v14 的 696 笔 / −45.1R 与 v15 的账本不可比。目前无解，只能各自累计。

## 三、已被验证为**假**的东西 —— 别再重做一遍

外部审阅者请特别注意这一节，这些都花过代价：

| 结论 | 证据 |
|---|---|
| 方向**不可**由 ribbon / Phase / 跳空方向 / 首小时方向 / 位状态预测 | 三轮检验、四类工具 |
| 具名斐波那契比例**不特殊** | 安慰剂梯子：残差 ≤0.76σ；整条梯子平移后完成率 63.7% vs 真 GG 64.6% |
| 「月线箱内 = hard mode」**不成立** | 20 年样本；据此过滤会误伤 43% 的交易日 |
| 「ATR 已走 >70% 就别进场」**方向是反的** | 六个时段全部同号 |
| **收紧任何门槛只减少笔数，不改善每笔期望** | 8 个变体压掉 83% 频率，均 R 始终 −0.184~−0.045 |
| 「离 13 近 / K 小 / 不追」三条闸门**使结果更差** | t = −4.82 / −2.06 / −3.97（`V15_ENTRY_LOCATION`） |
| **^GSPC 不能代理** CAPITALCOM:SPX500 做位相关研究 | 246 天 ATR 比值 mean 1.117 / sd 0.083 / 范围 0.826–1.418 |
| Golden Gate 复现**不是**样本外 | 窗口重叠约 2 年、时段档位错开半小时、参考值来自截图目视 |

**唯一通过多重比较校正的正面结论只有一条**：
最小风险距离 ≥ 0.12 ATR（D4≥中位，均净R +0.005 vs 基线 −0.142，z_sel +4.37）。
**而且它只是把结果从"亏"改善到"打平"，不是盈利。**
