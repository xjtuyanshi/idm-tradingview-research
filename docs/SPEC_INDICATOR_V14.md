## 1. 指标的三层结构

```
┌─ 第一层：地图（永远显示，不需要信号）────────────────────────┐
│  日/周/月/季 四级 ATR 位梯                                     │
│  夜盘高低、盘前高低、PDH/PDL                                   │
│  Pivot Ribbon（8/13/21/34/48）+ TimeWarp 上级周期带            │
│  Phase Oscillator（3m 与 10m 配对显示）                        │
└────────────────────────────────────────────────────────────┘
┌─ 第二层：预算（回答"此刻值不值得动手"）──────────────────────┐
│  剩余行程预算表（按时刻查表）                                  │
│  今日目标上限建议（由夜盘区间宽度决定）                        │
│  红线告警：14:30 后 / 11:30 后的目标现实性                     │
└────────────────────────────────────────────────────────────┘
┌─ 第三层：剧本（双分支 if-then，永远两边都写）──────────────┐
│  多头分支：条件 → 目标（具名位）→ 该目标的基准率[CI, n]        │
│  空头分支：同上                                                │
│  当前 setup 状态机（Ribbon Recovery / Vomy）走到第几步         │
└────────────────────────────────────────────────────────────┘
```

**核心设计原则（直接来自用户那句"图上看不到任何有用价值"）：
第一、二层永远有内容，与有没有信号无关。第三层的两个分支也永远都写。**

|---|---:|---:|---|

| 夜盘区间/日ATR | 当日触及 ±1 ATR 的概率 |
|---|---:|
| 窄 <0.4 | **2.6%** |
| 中 0.4–0.8 | 16.7% |
| 宽 >0.8 | **56.2%** |

→ 开盘前就能给出"今天别挂 1 ATR 目标"的建议。


### 3.3 【2026-07-26 补充】两条来自作者的规则，检验后需要区别对待

**① 「ATR 已走 < 70% 才可入场」——不要实现，方向反了。**
分时刻控住混杂后，六个时段全部同号且显著：已走 ≥70% 的日子，
之后再走 0.236 ATR 的概率**更高**（09:30 99.1% vs 91.4%，14:30 35.0% vs 12.6%）。
换成「距锚方向距离」的定义，六段仍同号同向（z≈−1.7）。
机制是波动率聚集：区间是持续的，不是会被用完的预算。
详见 `research/reports/TRIGGERBOX_AND_ATR_COVERED_2026-07-26.md`。
→ **面板显示「当日已走 X% ATR」必须是中性描述，不得写成「剩余空间不足」。**

**② 「trigger box 穿越可靠」——可以画，不可声称是边缘。**
真箱（±0.236）与同宽度平移箱的穿越率无差别（四格三格 z<1.5，一格 +2.01，
四格 Bonferroni 门槛 ≈2.5 不过关）。穿越率本身是真的（到锚 56–63%、
完整穿越 50–56%），但**任何等宽箱子都一样**。

**③ 【工具代际】不要把 Ripster 云与 Saty Ribbon 混在一起。**
2022 年的视频用 Ripster 云（5/12、8/9、20/21、34/50）；
2023 年的视频用 Saty Pivot Ribbon（8/13/21/34/48）。**没有任何一集同时用两者**——
48 在功能上取代了 34/50 云作为 regime 线。合并两者会造出一个他从未用过的系统。
用户图上两个都挂着是可以的（那是用户的选择），但**指标内部必须选一代实现**。

**④ 【不要硬编码 0.382】** Vomy 的衰竭位是变量：Vomy 视频里是 +0.382，
盘前视频的实盘复盘里是 call trigger（+0.236）。做成输入。

**⑤ 【Golden Rule of Trend】** = Ripster 的规则，Saty 只是转述：
**在 34/50 云之上看多，之下看空。** 就这一句，没有入场、止损、目标。
它是一个二元 regime 状态，不是一个 setup。

## 4. 第三层：两个 setup 的状态机

### 4.1 Setup A：Ribbon Recovery（他的**主要**入场，我们三轮都没测过）

**[证据等级 A：作者逐字]** [QMJ_rg3phPA 13:37 / 14:23]
> "you break above the 13 EMA, above the 8, it starts to hold the ribbon —
> **there is a surgical entry**" … "**recovers the 13, that's a good entry right there**"

```
S0  上级周期 ribbon 排列成型（给方向）
S1  执行周期价格回踩进入上级 8/13 带（最深不超过 21）
S2  价格【收复并守住 13】  ← 入场触发
S3  止损：收盘跌回 13 下方（结构性，非固定点数）
S4  目标：ATR 位逐级分批（下一位 → 再下一位 → runner）
【否决】价格远离 ribbon 时不是入场
        原话 [k8yKdDDqN-M 8:32]："wait for it to recover the 13"
```

### 4.2 Setup B：Vomy / inverse Vomy（趋势反转变体）

**[证据等级 A]** 完整规则见 `SPEC_VOMY_FROM_AUTHOR.md`。要点：

```
V0  五条 EMA 排列（清晰趋势）
V1  遇阻力形成双顶/单顶（⚠ 位共振是加分项，**不是必要条件**）
V2  收盘破 8 与 13
V3  回抽 13  ← 入场A（激进）"most of the move down"
V4  破【并守住】48  ← 入场B（确认）
V5  完整收于 48 下方后的下一次回踩 ← 入场C（保守）
【禁止】48 破位之后追（"don't get in after the 48 break"）
【未定参数】"break and hold" 从未被量化 → v14 必须做成输入并做敏感性
```

**注意**：ribbon 变色是 V 的**结果**不是触发（作者：Vomy 的作用是"**anticipate** that"）。

### 4.3 Golden Gate 的正确用法：**持仓规则，不是入场信号**

**[证据等级 A]** [d43HaLb765k 6:00 / 19:15]
> "an awesome way to **stay in trades**" … "I don't use it particularly as a
> straight-up swing setup, **I use it in conjunction**"

→ v14 里 GG **不产生入场**。它只在**已持仓**时显示："当前 GG 状态 + 此刻完成的历史基准率"。

## 6. v14 明确【不做】的事（反面清单）

1. **不发方向信号。** 三轮检验、四类工具、独立实现：方向不可预测。两个分支都写。
2. **不把 Conviction Arrows 接推送**（作者本人声明它不是买卖信号）。
3. **不用 A/B/C 评级**（旧系统的发明物，无基准率）。
4. **不用 R 倍数做目标**（他从不这么说；目标永远是具名位）。
5. **不做「月线箱内不交易」的 regime 过滤器**（20 年样本已否定，会误伤 43% 的交易日）。
6. **不在图上暗示位有磁铁效应**（两轮独立检验：具名比例的残差 ≤2.2σ，无台阶）。
7. **不因为盈亏比高就认为有期望值**（已实测证明：打平胜率与几何零假设一一对应）。
