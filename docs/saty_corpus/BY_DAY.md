## 术语速查（Saty 黑话）
- **GG** = Golden Gate（0.618 通道，"open→closed"=触发到完成）；**Scalp/Morning/Multiday/Swing/Position GG** = 不同周期的 GG。
- **PO** = Phase Oscillator；"PO extreme / -175 / -200 / accumulation" = 相位振荡极值/吸筹。
- **Vomy / iVomy** = 均值回归展开形态（自创词）；**Chopzilla / CHOPEX** = 绞肉机行情。
- **PDC** = 昨收；**PML/PMH** = 前市低/高；**LOD/HOD** = 日内低/高；**s/r flip** = 支撑阻力翻转。
- **10m 21 / D21 / W21 / H200 / D48** = 各周期 EMA（21/48/200）。**ribbon** = 均线带。
- **LB** = SPX Volume Leaderboard（前 10 大合约）；"LB clear"=无 ITM（有归零风险）；"LB shake / contracts to shake"=洗合约。
- **三/十 (3/10)** = 3m + 10m 双周期确认；**green dot** = 90 天一致性挑战的当日盈利点。
- **ATR levels** = 自研的 +1/-1/+2 ATR 目标位（Yearly/Quarterly/Monthly/Daily 多层）。
