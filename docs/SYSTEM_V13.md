## 2. 两条铁律（碰前必读）

1. **字节冻结引擎**：`f_v11_engine(...)` 区域逐字节比对（契约测试 `_unique_slice`）。
   任何改动 = 破坏冻结 = 不可以。喂给函数（f_pick_*/f_candidate_* 等）不在字节区内
   但改动会改行为：动之前必须过 replica 回归。
2. **v13 跟单规则预登记冻结**：只跟 LEVEL_REJECTION；时段 09:30–14:00 ET；单仓；
   止损开仓后一格不动；T1 兑现 50%、T2 兑现 25%、剩余 25% 持到日终或原止损；
   全额止损→同向冷却 30 分钟；逆势拒绝默认跟；最小止损距离 3.0 点；
   前向起点 2026-07-22 18:00 ET（`F12_FORWARD_START_MS = 1784757600000`）。
   **改任何一条 = 记分板清零重来。**

## 3. 架构速记（详见 ARCHITECTURE_V12.md）

- 纯核心 `f_f12_core(...)`：函数级 var 状态，每调用点一个实例；3m 主机直接调用，
  10m 窗通过 `request.security_lower_tf` 对同一核心做确定性重演（两窗必然一致）。
- 事件以 24 字段 primitive 元组返回；效果层（标签/推送）与状态机严格分离
  （CE10057 纪律：核心里零 alert()/label.new）。
- 显示层级：真实跟单 = 大号实心标签（跟多/跟空/平多/平空±R）；研究信号 = 小号
  A/B 级标记；13.1 起 C 级与逆势小标默认隐藏（输入开关可恢复）。
- 参数指纹 `f12OfficialConfigOk`（19 引擎参数 + CAPITALCOM:SPX500）不匹配时
  面板降级为"⚠未登记配置"；显示类开关不在指纹内。

## 5. 前向协议与淘汰制

- 账本 = TV 警报日志里的 META 行（append-only）；图上记分板受加载窗（3m×1500 根
  ≈3 天）限制，长期以外部账本为准。
- 淘汰线（60 笔一批）：累计 ≤ −10R 硬淘汰；前 20 笔实测摩擦 > 0.4 点结构性淘汰；
  60 笔内无一笔 ≥ +1.5R 日终 runner 经济性淘汰。
- "证实"标准：≥385 笔且费后 t ≥ 1.645（单边 5%，按日聚类方差），第 385 笔只检验一次。
- 成本双轨：毛 R 与费后 R（0.5 点/往返假设）并行记账；model_R 与 actual_fill_R 分离。

## 7. 运维手册（Runbook）

1. **改代码上线流程**：本地改 → `pytest research/tests` 全绿 → `pbcopy` →
   TV Pine 编辑器（图例 `{}` 打开）JS 聚焦 `.monaco-editor textarea.inputarea` →
   ⌘A/⌘V/⌘S → `pine-facade …/translate/<id>/last` 查 `success:true`（缓存要加
   随机参数重询）→ `/get/<id>/last` 拉源码做 LF 归一化 SHA 比对。
2. **警报生命周期法则**：TV 警报在创建时绑定脚本版本快照。**每次推送行为变更后
   必须删除+重建警报**，并在条件下拉里核对版本号；重建后到 Notifications 面板
   确认 "Notify in app" 勾选、日程 24/7。"Alert saving failed" 可能实际已成功
   ——先刷新面板再判断。
3. **图表实例更新**：库脚本更新后，图上旧实例不会自动升级。最省事：删实例重加
   （默认参数=官方配置；服务端警报不受影响；记分板按加载窗重算）。
4. **Pine v6 陷阱实录**：无 `dayofyear()` 函数（用 year/month/dayofmonth 拼日键）；
   define-before-use（CE10271）已犯 3 次——新函数一律放调用点之前；alert() 不得
   进入喂 security 的数据流（CE10057）；粘贴可能落进图表注释（先 JS 聚焦编辑器）。
5. **验收一条链**：心跳推送到手机 → META 行进警报日志 → 图上标签/记分板一致
   → 三者对齐才算"活着"。
