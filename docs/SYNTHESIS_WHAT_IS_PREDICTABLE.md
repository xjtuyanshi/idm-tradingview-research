# 综合结论：什么可预测，什么不可预测（2026-07-25）

> 依据本周末六项独立研究：GG 复现、夜盘/盘前位、月线 regime、位转移地图、
> Pivot Ribbon、Phase Oscillator、时间结构。每一项都在各自报告里附了置信区间、
> 家族规模与两比例检验。本文只做汇总，不引入新数字。

## 一、六项研究指向同一个分界线

把所有结论按"它预测的是什么"重新排列，会看到一条极其干净的分界：

### ❌ 方向：全部工具、全部样本、全部失败

| 工具 | 最干净的方向检验 | 结果 |
|---|---|---|
| Pivot Ribbon（8/21/34） | P(先摸上方位 \| 只摸一侧) | above 52.0% vs 基准 52.0%，**z = 0.00** |
| Ribbon 回踩反弹（候选入场） | 同上，143 次事件 | 49.7%，z = −0.68（**低于**基准） |
| "Holding H21"（Saty 原话 setup） | 同上，389 次事件 | 47.8%，z = −1.77（**低于**基准） |
| 日线 ribbon + 小时 ribbon 叠加 | 增量检验 | z = −0.55 / −0.03，**叠加不加分** |
| Phase Oscillator 七个分区 | 波动率中性化后 P(先到上方) | 全部落在 43%–57%，**无一通过 z≥1.96** |
| 开盘在 ±0.236 带内 | 先触上还是先触下 | 53.6%，z = +1.31，不显著 |
| 21 EMA vs 滞后 21 根的安慰剂线 | 对照 | 52.2% vs 53.2%，**真 pivot 不比过期的线强** |

**Ribbon 报告的原话**：全部方向格 |z| 最大 2.21，低于 306 格的家族阈值 3.77，
且符号在小时线与 5 分钟线互相矛盾。**这就是噪声的定义。**

### ✅ 行程与空间：全部成立，而且效应很大

| 变量 | 最干净的统计 | 效应 |
|---|---|---|
| **时刻** | 09:30 建仓 P(最优边≥0.236 ATR)=96.3% → 14:30 只剩 **49.7%** | 巨大、单调 |
| **时刻** | 前两小时承载全日 **69.3%** 的区间发现 | 巨大 |
| **时刻** | 14:30 建仓时，当日高低点已定死的概率 **46.0%** | 巨大 |
| **GG 触发时刻** | 完成率 89.7%（开盘）→ 70.8%（09:30）→ 0%（15:30） | 巨大、单调 |
| **夜盘区间宽度** | 当日触及 ±1 ATR：2.6%（窄）→ 56.2%（宽） | 巨大、单调 |
| **夜盘位置** | 当日完成 GG：5.6%（未过 0.236）→ 64.0%（已过 0.382） | 巨大、单调 |
| **Ribbon** | 上下 barrier **双向**触及率，z 达 5.06–10.09 | 真实（但约一半可被"前 3 根振幅"免费替代） |
| **Phase** | full_bull + distribution 区 → 当日走不出 ±0.236 的概率 32.7% vs 11.7%（z=−3.62） | 真实，是**否决位** |
| **具名位间距** | 0.236→0.382 = 78.4%（n=3289） | 真实但**是几何必然，不是优势** |

## 二、由此得到的唯一诚实设计

**旧系统的根本错误不是参数错了，是它在回答一个不可回答的问题。**
它的每一个输出——买A/卖B/逆多、A/B/C 评级、T1/T2——都是在说"往哪边走"。
六项研究说：**这个信息不在我们测过的任何工具里。**

而"还有多少行程、下一个具名位在哪、现在动手值不值得"——**这些全部可预测，
而且效应量大到肉眼可见。**

### 于是系统必须换一个输出

| | 旧系统（信号发生器） | 新设计（地图 + 预算 + 剧本） |
|---|---|---|
| 核心输出 | "买 A 级信号" | "你在 0.382 与 0.5 之间；上破 0.5 → 目标 0.618（此刻完成率 53%[CI] n=30）；跌破 0.382 → 目标 PDC（47.2%）" |
| 方向 | 系统给 | **系统不给**，两个分支都写 |
| 目标 | 风险的 R 倍数 | **具名位**（Saty 从不用 R 倍数） |
| 无信号时 | 死图 | **剧本本身就是内容** |
| 时段 | 一条普通规则 | **概率表的第一索引维度** |

### 三条可以直接写进引擎的红线（来自时间预算表）

1. **14:30 之后不开需要 0.236 ATR 行程的新仓**——那一刻即使方向全对也只有 49.7%。
2. **11:30 之后不挂 0.382 ATR 以上的目标**——锁定方向后命中率只剩 27–32%。
3. **开盘前用夜盘区间宽度定今日目标上限**：窄（<0.4 ATR）→ 触及 ±1 ATR 只有 2.6%，
   别挂 1 ATR 目标。

## 三、这与 Saty 本人的做法完全一致（这一点很重要）

我们的数据说方向不可预测。而 Saty 的实际行为**恰恰不预测方向**：

- 九篇盘前帖，**每一篇都写两个分支**（`docs/SATY_PLAYBOOK_CORPUS.md`）。
  他从不说"今天做多"，他说"若守住 X 上破 Y → 目标 Z；若跌破 X → 目标 W"。
- 他的目标**全部是具名位**，没有一次是 R 倍数。
- 他 **11:47 收工**，自述"专注开盘后头两小时，争取中午 12 点前收工"——
  与我们的时间预算表逐条吻合。
- 他用 "**3m extreme / 10m has room**" 决定减仓与留 runner——
  这正是 Phase 报告里唯一活下来的用法：**成熟度/否决层，不是入场层**。

**换句话说：我们花一个周末用数据独立走到了他早就在做的地方。**
这不是巧合——这是他的方法为什么能长期存在的原因。

## 四、必须同时说清楚的否定结论

1. **Pivot Ribbon 不是我们缺的入场层。** 它只能挂在"目标距离/止损宽度/今天值不值得做"
   这一层。花力气把它做进图里可以（它是 Saty 的语言），但**不要指望它指方向**。
2. **"月线触发箱 = hard mode" 不成立**（20 年样本，五项指标三项方向相反）。
   听从业者叙事建规则，必须先过检验。我们的两笔前向亏损**不能归因于 regime**。
3. **Golden Gate 不是入场信号**，它的报酬（0.236 ATR）小于自身路径噪声（0.303 ATR）。
   它是目标与概率层。
4. **"等触发位被触及再入场"这条规则本身有结构缺陷**：约 **46%** 的交易日开盘时
   ±0.236 已被跳空穿透。任何入场规则必须先回答跳空日怎么办。
5. **Yummy / Vomy 至今没有可靠定义**（三个候选定义几乎从不同时触发 = 三个不同策略）。
   只有原作者本人能定；在定下来之前**不要实现**。
