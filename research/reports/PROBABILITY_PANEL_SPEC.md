## 0. 这份规格要解决的那句抱怨

> **"从你那个图表里面，不管你有没有什么信号开仓，我看不到任何有用的价值。"**

诊断：旧系统只在"有信号"时说话。而**信号占交易日的比例很小，且入场层至今未被任何研究证实存在**
（GG 报告 §2、时间结构 §4.4、ribbon §0、phase §0 四份独立报告都得出同一个否定结论）。
所以旧图在绝大多数时间里是一张死图，而在它开口的那少数时刻，说的还是一件没有证据的事。

Saty 的图不是这样。他的图在**任何时刻**都在回答三个问题：

| 问题 | 本面板对应行 | 没有信号时还有值吗 |
|---|---|---|
| 我在哪？ | ① 我在哪 | ✅ 位置永远存在 |
| 现在还剩多少时间/行程？ | ② 时钟 | ✅ **这一行与行情无关，只与时钟有关** |
| 今天是什么类型的一天？ | ③ 今日模式 | ✅ 10:30 后永远有判定 |
| 下一站在哪、多大概率到？ | ④⑤ 双向阶梯 | ✅ 两侧永远同时显示 |
| 回锚的概率？ | ⑥ 回锚概率 | ✅ |
| 哪些事我**知道**是不可知的？ | ⑦ 已知为空 | ✅ **这是最反直觉但最重要的一行** |

**核心设计判断：面板的价值不来自"它什么时候开口"，而来自"它从不闭嘴，且从不撒谎"。**
第 ⑦ 行（把已被证伪的东西明确写出来）是本设计与 v11/v12 最大的区别——
旧系统的失败不是因为它沉默，是因为它在不该说话的时候编了话。

## 1. 五条设计纪律（违反即作废）

| # | 纪律 | 为什么 |
|---|---|---|
| **D1** | **任何百分比必须同时显示 n 与 Wilson 95% 区间。** 没有区间的比例不许上图。 | `satylab/stats.py` 的开篇注释："a base rate without an interval is a story"。 |
| **D2** | **样本不足的格子显示"样本不足 (n=..)"，绝不编数字，也绝不留空。** 留空会被读成"没有行情"，编数字会重演 v12。 | 见 §3.3 的分级规则与 §3.4 的可服务性矩阵。 |

| 剩余分钟 | 时钟 | 390 / 330 / 270 / 210 / 150 / 90 / 30 |
| **P(还能再走 0.236 ATR)｜最优边（上界）** | `BASERATE_TIME_STRUCTURE` §3.1 | 09:30 **96% [95,97]** → 11:30 **85% [82,87]** → 14:30 **50% [46,53]** → 15:30 **26% [23,29]**，n=722 |

**两条必须原样印在面板 tooltip 里的读法**（`BASERATE_TIME_STRUCTURE` §3.2）：

- **"最优边"是上界。** 任何声称"14:30 后我的 0.382 目标能中 40%"的系统一定有错——上界只有 24.2%。
- **"锁定方向"是零技能基线。** 一个真有 edge 的入场必须显著高于它。这条线同时是未来入场层研究的及格线。

**红线（引擎硬规则，`BASERATE_TIME_STRUCTURE` §0）**
1. **14:30 之后不再开需要 0.236 ATR 行程的新仓**——即使方向全对也只有 49.7%，且 **46.0% [42.4,49.6]** 的交易日在 14:30 那一刻高低点**都已经出现过了**。
2. **11:30 之后不再挂 ≥0.382 ATR 的目标**——锁定方向命中率已跌到 27–32%。
3. 前两小时承载全日 **69.3%** 的区间发现；13:30 那一小时有 **51.8% [48.2,55.4]** 的概率对全日区间**零贡献**（中位新增区间 = 0.0%）。

### ④ / ⑤ 双向阶梯（核心查表）

**起点 = 该方向今日已触及的最高档；条件变量 = 该档的首触时段（不是当前时段）。**

> 这是实现上最容易搞错的一点，也是我在参考实现里改掉的一个真 bug：
> 研究里的条件是"L 于哪个时段**首触**"，不是"现在几点"。用当前时段查表会读错格子。
> 面板必须显示"起点 X 于 hh:mm 首触"，让用户能自己核对。

对每一个更远的档显示：`起点 → 目标 @ 绝对价格   概率 [CI] n=..   [数据源档次]`

**来源**：`BASERATE_LEVEL_TRANSITIONS` §D1/§D2（小时线，按首触时段）、§C1/§C2（20y 日线，无条件）。

全时段 67.6% n=395，与报告 §D1 同行同值）。

**当该方向今日尚未触及任何具名位**（例如价格在触发箱内，或已跑到另一侧很远）：

`需走距离 = |目标 ratio − 当前 ratio|`，然后在 ② 的"锁定方向"表里内插。
这仍然是查表，不是模型，且**永远有值**。

## 3. 状态 → 概率 的查表逻辑

### 3.1 状态向量

面板每根 K 收盘重算一次，输入**只有**这五项（全部为已实现信息，无前视）：

```
S = ( r_now      当前价在位图上的 ratio
    , r_hi, r_lo 今日 running high/low 的 ratio        → 决定"今日已触发哪些位"
    , ft[side][L] 每个已触及位的【首触时段】            → 最强条件变量
    , slot        当前时段 (09:30..15:30)              → 时钟表索引
    , mode        首小时判定 (未过0.236/只到0.236/已过0.382) + 首小时振幅
    )
```

**ribbon / phase 刻意不进入方向查表**，只允许出现在"量程/波动率"注解里（理由见 §5 第 6 条）。

### 3.2 三条查表链

| 查询 | 链条 |
|---|---|
| **阶梯概率** `P(到达 L′ \| 今日已触 L)` | ① 小时线 × 首触时段 → ② 小时线合并全时段 → ③ 20y 日线无条件 → ④ **样本不足** |
| **距离概率**（该方向无已触位时） | ② 的锁定方向表按距离内插（0.118 / 0.236 / 0.382 / 0.5 四个锚点，超出则给单边界 `≥` / `≤`） |
| **回锚概率** | §2⑥ 的固定表（小时线严格口径），同样过分级规则 |

**面板必须显示实际服务的那一档**（参考实现打印 `[1h/09:30]`、`[1h/全时段]`、`[20y日线/无条件]`）。
用户有权知道他看到的 70% 是"这个时段的 70%"还是"合并之后的 70%"——**这两件事的差别可以有 20 个百分点。**

### 3.3 分级规则（决定何时显示"样本不足"）

事前定死，不调参：

| 档 | 条件 | 面板显示 |
|---|---|---|
| **A** | n ≥ 100 **且** Wilson 区间宽度 ≤ 20pp | `70% [63,77] n=165` |
| **B** | n ≥ 30 **且** 宽度 ≤ 35pp | `82% [68,91] n=40 ~宽`（带宽区间标记） |
| **C** | 其余 | **`样本不足 (n=29)`** |

**为什么阈值定在这里**：面板被问的唯一问题是"这个目标现不现实"，即"这个数离 50% 有多远"。
一个宽 35pp 的区间**在结构上无法区分"多半会到"和"抛硬币"**，所以它不是一个答案，只是一个数字的形状。
n=30 是二项区间开始收敛的量级；n=100 是宽度普遍落到 20pp 以内的量级。
**这两个阈值只设过一次，没有扫描过其它取值**——扫描它们就是又一次网格择优。

**读法（三条结论，都很难听但必须写在这里）**

1. **全部 448 个时段格里，只有 55 个是 A 档、68 个是 B 档，325 个（73%）必须显示"样本不足"。**
   730 天的小时线一共就 722 个交易日，切成 2 方向 × 7 起始档 × 8 时段 = 112 个格子之后，
   每格平均只剩几十个样本。**这是数据的硬边界，不是实现的懒惰。**
2. **可用的格子几乎全部集中在 OPEN 与 09:30 两列。** 10:30 只有 4 个格子够 B 档，
   11:30 及以后**一个都没有**。这与时间结构报告的结论是同一件事的两种说法：
   **盘中的行情主要发生在前两小时，所以只有前两小时有足够的样本去描述它。**
3. **1.272 那一行整行不可服务**（最大 n=23）。面板在扩展区必须回落到 20y 日线的无条件格
   （多 1.272→1.618 = 33.9% n=375；空 = 51.9% n=503），并明确标注数据源已降级。

**运行时的实际后果**（§6 的三个真实面板都能看到）：即使在一个完全正常的交易日，
"0.5 于 11:30 首触"这样的常见状态也会落到 C 档（n=22），面板会自动回落到全时段格（n=322）并把这件事印出来。
**这正是设计意图**——用户看到的是"我们只有这个精度"，而不是一个假装很精确的数字。

### 3.5 必须硬编码的两条修正

| 修正 | 原因 | 面板必须显示的数字 |
|---|---|---|
| **跳空档 GG 完成率去污染** | 开盘即穿透 0.382 的日子里，**开盘价本身就已经在 0.618 之外**的占 40.9%(81/198)。那不是行情，是既成事实——你下不了那一单。 | 本脚本独立复核：多头 38/117 = 32.5%、空头 43/81 = 53.1% 的"跳空触发"开盘已过 0.618。**剔除后：多 84.8% [75.3,91.1] n=79；空 89.5% [75.9,95.8] n=38 ~宽；合并 86.3% [78.9,91.4] n=117**，而非 89.7%/95.1%。（与 `BASERATE_TIME_STRUCTURE` §4.2 的 86.3% n=117 逐位吻合） |

## 4. 盘前剧本自动生成（Saty 双向 if-then 格式）

**生成时刻**：开盘前。**输入只有前一交易日信息**（锚=前收、ATR=前日 Wilder ATR(14)、前日高/低），
所以整张剧本在开盘铃响之前就已经锁定，事后无法调整——这是它可被审计的前提。

### 4.1 模板

```
【盘前剧本 · {SYMBOL} · {DATE}】  锚(PDC)={anchor}  ATR(前日,Wilder14)={atr}
                                 前日高={prev_high}  前日低={prev_low}

本剧本只陈述条件概率，不预测方向。两个分支都写出来，因为数据说方向不可预测
（触发箱内先上还是先下 53.6% [48,59] n=336，z=+1.31，不显著）。

── 若上破 +0.236 ATR = {price} （call trigger）──
   [开盘即穿透]   +0.236 → 目标 +0.382 = {price}   {rate} [{ci}] n={n}   [{source}]
   [09:30 段触发] +0.236 → 目标 +0.382 = {price}   {rate} [{ci}] n={n}   [{source}]
   [全时段合并]   +0.236 → 目标 +0.382 = {price}   {rate} [{ci}] n={n}   [{source}]
   ... 同样三行 × (0.382→0.618) × (0.618→1.0) ...
   [尾部]         +1.000 → +1.272 = {price}   {rate} ...
   ⇒ {尾部天花板结论}

── 若跌破 −0.236 ATR = {price} （put trigger）──
   ... 完全对称的同一组行 ...

── 无论哪个分支都成立的三条 ──
── 本剧本明确不说的（固定文案）──
```

**格式硬规则**：
- 两个分支的行数、字段、排版**必须完全对称**。任何不对称都会被读成方向暗示。
- 每一行都带 `n` 与 `[数据源档次]`。C 档的行**直接不打印**（而不是打印一个模糊数字）。
- 尾部结论按方向不同，且空头那条**必须带反读警告**。

## 5. 反面清单：面板**不该**显示什么

每一条都对应一次已经付过学费的错误。

| # | 禁止显示 | 教训来源 |
|---|---|---|
| **1** | **任何"看涨 / 看跌 / 偏多 / 偏空"标签**，包括箭头、颜色偏置、把某一侧排在前面 | 方向格子集体不显著。ribbon z=+0.00、首小时方向 z=±1.50、触发箱内 z=+1.31、phase 七分区全部落在 43–57%。**在这些数字面前显示方向就是编造。** |
| **2** | **入场价、止损价、目标价三件套** | GG 复现 §2：赢单最深回撤中位 0.303 ATR，而 GG 的报酬只有 0.236 ATR；止损放 0.236 会洗掉 33% 的赢单，放到锚则 R:R = 0.62:1、打平需 61.7% 胜率。**触及概率不能推出交易几何。** |
| **3** | **A/B/C 信号评级、信号计数、"今日已发出 N 个信号"** | 这正是 v12 的构造：六源位池 + A/B/C 评级，880 个统计量三层择优，家族极值 p=0.87，前向第一天 2 笔全亏。 |
| **4** | **没有 n 和 CI 的百分比** | D1。一个孤零零的 "70%" 无法与 "70% [30,94] n=8" 区分。 |
| **5** | **n<30 或区间宽 >35pp 的格子里的数字** —— 必须显示"样本不足" | §3.3/§3.4。448 个时段格里 325 个属于这一类。**留空同样禁止**：空白会被读成"没有行情"。 |
| **6** | **把 ribbon / Phase 当方向票**（"ribbon 多头所以偏多"、"Phase extended 所以要反转"） | `BASERATE_RIBBON` §0（above 52.0% vs 基准 52.0%，z=+0.00）；`BASERATE_PHASE` §0（extended_up 做多赢面 49.6% vs launch_box 49.1%，z=+0.10）。**"extended 区不追"的正确理由是"大概率没行情"，不是"大概率反转"。** |
| **7** | **"首小时收阳所以今天偏多"这类生成文案** | `BASERATE_TIME_STRUCTURE` §5.4c 明确 null。引擎里所有此类文案应删除。 |
| **8** | **混合的 GG 完成率（66%）** | 必须拆成跳空 85.9% n=936 / 盘中 51.5% n=1666，z=+17.53。 |
| **9** | **未去污染的跳空 GG 完成率（89.7% / 91.9% / 95.1%）** | §3.5。40.9% 的"完成"发生在你能下第一笔单之前。 |
| **10** | **"月线触发箱内 = hard mode，今天别做"这类 regime 过滤器** | `REGIME_MONTHLY_BOX` 全面推翻：箱内触及 ±1ATR **34.6% vs 箱外 28.6%（z=+4.44）**、假突破**更少**。若照叙事实现，会在 43.1% 的交易日里关掉系统，而那些日子统计**更好**。 |
| **11** | **周内效应文案（"周四更好"）** | 周四 z=+2.38，5 次比较的 Bonferroni 门槛是 2.58 → 不成立。月初效应虽真但只有 8pp，**是备注不是规则**。 |
| **12** | **期望值 / R 倍数 / 胜率预估** | 没有任何研究支持一个入场层，因此也就没有 R 可算。显示 R 等于宣称我们有一个我们没有的东西。 |
| **13** | **ATR 长度、锚定方式、位比例的用户可调参数** | 整张表建立在"锚=前收、ATR=前日 Wilder ATR(14)"这**一个**口径上。开放参数 = 邀请用户做我们刚刚发誓不做的网格搜索。 |
| **14** | **基于"触及某个位"的推送 / 警报** | 触及率高的位在几何上通常离得近（0.236→0.382 只隔 0.146 ATR，78% 的到达率说明的是"挨得近"）。把几何必然做成警报 = 制造噪声。 |
| **15** | **倒计时到"下一个信号"、"等待入场"之类的等待态 UI** | 这会重新把面板变成"只在有信号时有用"。面板没有等待态——它每一刻都在回答同样的六个问题。 |
| **16** | **在没有行情时隐藏 / 收起面板** | 这是 v12 那张死图的根因。**行情越少，② 时钟行与 ③ 今日模式行的信息价值越高**——那正是它该大声说"今天没有"的时刻。 |

## 7. 家族账本与诚实边界

### 7.1 家族规模

脚本自己数：**651 个格子**（时段转移 448 + 合并转移 56 + 20y 日线 56 + 预算 91）。

**但这不是 651 次新检验。** 面板是一个**查表器**，它重算的是已发布报告里的同一批表：
`BASERATE_LEVEL_TRANSITIONS`（447 格）、`BASERATE_TIME_STRUCTURE`（385 格）、
`BASERATE_OPENING_TYPE`（409 格）、`BASERATE_RIBBON`（306 格）、`BASERATE_PHASE`（283 格）。
**本规格没有做任何新的假设检验，也没有从任何网格里挑格子。**
唯一的新自由度是 §3.3 的两个分级阈值（100/20pp、30/35pp），它们只设过一次、未做扫描。

### 7.3 必须写在面板"关于"页里的边界

1. **小时线只有 730 天（2023-08 起），全部落在一段偏低波动的牛市。** 时段结构在 2008/2020 型环境下未经检验。
   20 年日线缓解了这一点，但日线无法回答"当日什么时候"。
2. **本面板的所有概率都是"触及概率"，不是盈亏。** 从触及到可交易之间隔着交易几何这道墙，
   而那道墙在 `BASERATE_LEVEL_TRANSITIONS` §H 里被证明**在小时线分辨率上不可判**
   （唯一决定性结论是负面的：多头 1.0→1.272 连上界 41.9% 都低于打平线 44.0%）。
3. **数据是 RTH-only，而 Saty 全套模板标注 (ETH)。** `SPEC_PIVOT_RIBBON` 实测开盘第一小时
   ETH/RTH ribbon 状态仅 48.8% 一致。**面板的 09:30 那一行不是他看到的那条线。**
   若接 CFD/期货标的（有夜盘），§4.3 的三张表才可用，且必须重新校准。
4. **Wilson 区间假设日间独立**，而 ATR 有自相关。`BASERATE_LEVEL_TRANSITIONS` §K 用月度块自助法
   重算了 8 个头部格子，与 Wilson 最大差 0.4pp——所以在这些量上自相关不构成问题，但换格子需重验。
5. **整张地图绑定"锚=前收、ATR=前日 Wilder ATR(14)"这一个口径。** 换 ATR 长度或换锚会整体移动所有数字。
   **这个网格没有被搜索过，也不应该被搜索**——那正是上一次犯的错。
6. **入场层仍然缺失。** 本面板是目标层 + 概率层 + 时钟层。它诚实地不包含第四层，
   因为四份独立报告都没能找到它。**面板的价值命题不是"帮你开仓"，是"让你在不开仓的时候也知道自己在哪"。**

## 8. 一页交付摘要

- **面板 7 行，任何时刻全部有内容**；"没有信号"不是一个状态，因为面板从不以信号为中心。
- **每个数字都带 n 与 Wilson 区间，且标注它来自哪一档数据**（时段格 / 合并格 / 20y 日线）。
- **448 个时段格里 325 个（73%）必须显示"样本不足"**——可用的格子几乎全在 OPEN 与 09:30 两列，
  11:30 之后一个都没有。这是数据的硬边界，面板的工作是把它诚实地展示出来，而不是掩盖。
- **盘前剧本严格双向对称**，只用前一交易日信息生成，开盘前锁定。
- **反面清单 16 条**，每一条对应一次已付学费的错误；其中第 1、3、12 条直接对应 v12 的失败模式。
- **面板不解决入场问题，也不假装解决。** 它解决的是用户那句抱怨的字面意思：
  **让图表在任何时刻都能回答"我在哪、下一站在哪、到那里的概率多大、现在还剩多少时间"。**
