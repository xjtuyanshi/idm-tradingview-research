## 1 · 主诊断：R 的分母就是被分层的那个变量

### 1.1 恒等式先摆出来

纯括号一笔的净 R = 毛R − 0.6/S。所以：

```
ρ(D4, 点差成本R) = −0.989   (z = −22.5)     ← 按定义，点差成本 ≡ 0.6/S
每笔平均点差成本 = 0.0752 R                  ← 全样本均净R 只有 −0.142
```

**净R 里有一项，按构造就是 −0.6/S。** 任何按 S 分层再看净R 的表，都在测这一项。

### 1.2 五个位置变量：R 口径 vs 钱口径

`钱 = 净R × (风险距离/日ATR)`，即固定名义敞口下每 1 单位本金的日 ATR 盈亏。
这一列对 S 免疫。左边是 `V15_ENTRY_LOCATION.md` §3 汇总表里的那一列，右边是我算的。

| 变量 | 净R ρ (z) | **净钱 ρ (z)** | 报告的判词 | 钱口径下的判词 |
|---|---|---|---|---|
| D1 离参考线越远 | +0.173 (**+3.92**) | −0.032 (−0.73) | 无证据 | 无证据 |
| D2r 信号K越大 | +0.211 (**+4.82**) | −0.013 (−0.30) | **反向：追反而好** | 无证据 |
| D2b 实体越大 | +0.087 (+1.98) | −0.023 (−0.52) | 无证据 | 无证据 |
| D3 追得越凶 | +0.154 (**+3.50**) | +0.016 (+0.36) | 无证据 | 无证据 |
| **D4 止损越远** | **+0.392 (+8.89)** | **+0.054 (+1.22)** | **反向：止损越远越好** | **无证据** |

毛口径同样没有：ρ(D4, **毛**钱) = +0.054 (z = +1.23)。所以这不是点差一项造成的，
是整个 R 记账。

**唯一对下注方式免疫的那个口径，报告自己也算了**：D4 的超额 pp 趋势得分 z = **+2.19**
（全样本）/ +2.70（控制 D3 后）。**这才是 D4 的真实量级——不是 +8.86。**

### 1.3 ρ(|MAE|/风险, D4) = −0.505 的置换零分布

把 |MAE| 在样本内随机置换（破坏它与 S 的一切真实关系，保留两者的边际分布），
重算 ρ(|MAE_置换|/S, S)，2000 次：

| | ρ |
|---|---|
| 独立置换零分布 均值 | **−0.566** |
| 5% / 50% / 95% | −0.609 / −0.566 / −0.521 |
| **实测** | **−0.505** |
| 实测在零分布的百分位 | **99.0%** |

对照：ρ(|MAE|, S) = +0.136 (z = +3.08)，即真实数据里 **止损越大、逆行的绝对幅度也越大**。
正是这一点把比值的相关从算术预测的 −0.566 往上顶到 −0.505。

**结论：这个数字里没有任何关于「窄止损的入场更差」的信息。** 它是 y/x 对 x 的相关，
零假设不是 0。本轮任务书把它当作「止损距离是唯一有效变量」的判决性证据，这个前提不成立。

### 2.1 V15_OVERNIGHT_ANATOMY —— **致命**（限「该分的是风险距离」这条建议）

钱口径下这句话不成立：

1. 「同号且都很大」在**夜盘这一半是 +0.0039，t = +0.37** —— 而夜盘正是这份报告的全部主题、

   **两个候选变量在钱口径下是同一个量级，谁也不压倒谁。**「A 是稳定的、B 会换符号」
   这个对比是 R 口径造出来的。
3. §3.1 那把 0.12 ATR 闸门在钱口径下：全样本 Δ = +0.0147 (t=+1.79)，RTH +0.0355 (t=+2.59)，

**反向的诚实条目**：把 D4 分成 5 层、层内比较夜盘 vs RTH、逆方差汇总，
钱口径 Δ = **+0.0099 (z = +1.87)**（不控制时是 −0.0140, t=−1.50）——控制止损距离之后
**夜盘反而略优于 RTH**。这与报告「夜盘不是病因」的方向一致，但 5 个层里 RTH 的层内 n
低到 12/15，逆方差汇总在这种失衡下不稳，只能当提示。

**站得住的部分（明确保留）**：本报告的核心主张是一组恒等式，它们对下注口径免疫，
一个都没被我推翻——
笔数份额 ≈ K 数份额 ≈ 16.5/23；止损比 0.49 ≈ 逐根振幅比 0.52；
点差成本比 1.7132 = 风险距离调和均值比 1.7132；路径效率 0.122 vs 0.186；
以及 §3.2b 那张 **T = k·S 扫描表**——它把零假设锁死成 1/(1+k)、只报**超额 pp**，

「该分的是风险距离，不是时钟」。正确的表述是：**在固定 R 下注的记账里，窄止损更贵；

### 2.3 V15_SCALE_MISMATCH —— **严重**（一条论证）+ 两条轻微

这一份是全批**唯一把 D4 效应放进「刻度被构造性统一」的世界里重跑**的报告（§7），
结论（v14 原样 +0.349 → T/S≡2 下毛R 残差 +0.058, t=+0.49）与我的钱口径检验
（ρ(D4,毛钱) z=+1.23）互相印证。这一节是本轮混淆控制的最高水位，应当被其它报告抄。

**严重 · §12.3 第 3 条的论证在自己的表里就不成立。** 报告反复引用：

> **没有一格的均净R 为正。**……如果两把尺子是亏损的**主因**，统一之后至少该有一格越过 0。没有。

这是 R 口径。同一份报告 §6 第三张表（「固定手数口径的 money」，报告自己称它
"消掉「小止损把 R 放大」这个幻觉"）里，**「反向具名位」那一列有三格为正**：
1.5R +1.84、2.0R +0.76、3.0R +0.25（总 money）。既然报告承认 money 才是消掉幻觉的列，
那么「统一之后一格都没越过 0」就是错的。

要公平：+1.84 总 money / 517 笔 = **+0.0036 ATR/笔**，量级微小、远不显著、且是 25 选 1。
它不构成正 alpha。但它是**这条论证的前提**，前提被自己的表推翻，论证就必须重写，
不能继续用「一格都没有」当作排除刻度错配为主因的直接证据。

**轻微 · §7.1 的三通道是减法残差，不是三个通道。** 把 v14 原样的 +0.349 与 T/S≡2 世界的
+0.140 相减，把差额 +0.209 整块记在「(1+T/S) 放大系数」上。但两个世界的 (p−p0) 本身
就不同——报告 §12.1 自己报了整体缺口从 −0.0367 变到 −0.0068，并诚实地标成「机制不明」。
那 +0.209 里含了这一块，它是残差不是通道。60% 这个占比不该被当成测量值引用。

**轻微 · 点差摩擦通道（23.6%）在固定名义敞口下恒等于零。** 每笔点差是固定的 0.6 点，
与 S 无关，所以在 money 差里精确对消——我实测 D4 闸门的 **Δ毛钱 与 Δ净钱 完全相同
（都是 +0.0157, t=+2.01）**。这一通道只在固定 R 下注时才是真钱。报告没有声明下注口径，
所以「机制清楚的 35%」里有 24 个百分点是口径依赖的。**35% 应改为 11%–35% 的区间，
并标注它依赖固定 R 下注。**

### 2.4 V15_REGIME_LAYER —— **严重**（一条断言 + 一条建议）

这一份的混淆控制是合格的：有净钱列、D4 五层分层、Mantel-Haenszel/逆方差汇总，
而且诚实地报告了「盒内×Recovery 控制 D4 后钱的那一半消失了一大半（z −2.06 → −1.37）」。

**严重 · §5 的「反例」方向是反的。** 报告写：

它比的是 **S=0.093 的边缘拒绝**（净均R −0.092 / 净钱 −0.0056）与 **S=0.137 的盒内交叉类**
（−0.293 / −0.0154）。两组止损差 47%，正是被指控的那个变量。按 S 配对重比：

|---|---|---|---|---|
| 边缘拒绝（报告） | 277 | 0.093 | −0.092 | −0.0056 |
| **v14 自身信号 S∈[0.08,0.11]** | **86** | **0.093** | **−0.022** | **−0.0016** |
| v14 自身信号 S∈[0.06,0.13] | 184 | 0.091 | −0.065 | −0.0040 |

**在同一个止损档上，边缘拒绝比 v14 的交叉类更差，不是更好。** 所谓的反例本身就是

（不显著），却在正文里升格成了「反例」。**这条断言应当撤回。**

**严重 · §9.3 建议 3 把唯一「被独立验证过」的资格给了 D4。** 原文：

按 §1 的诊断，那条「验证」（D4 闸门 z_sel = +4.37）在钱口径下是 t = +2.01，
在毛口径下是 t = +2.01，控制 T/S 后是 t = +0.49（该报告自己的 §7）。
**它不是三条里最硬的那条，它是三条里口径最脆的那条。**

### 2.5 V15_LEVEL_RETEST_AND_DIVERGENCE —— **严重**

**穿透深度按构造就是止损距离的一个加项。** 脚本第 441–442 行：

```python
stop = e.L - d * (e.depth * e.atr + STOP_BUF * e.atr)
risk = d * (entry - stop)
```

入场价是「离开该位 ≥0.05 ATR」的那根收盘，所以 `S/ATR ≈ |close−L|/ATR + depth + 0.02`。
实测：

| | 值 |
|---|---|
| ρ(深度, 止损距离) Spearman | **+0.656** (z = +26.4) |
| Pearson r | +0.617 |
| 深度占止损的平均比例 | 11.0% |
| 止损距离 sd | 0.0563 ATR |
| 回归掉深度后的残差 sd | 0.0443 ATR（少 21%） |

**报告全文 0 个钱列，也从未提到这个共线性。** 而它唯一的可执行建议是
「S2 值得画出来的是**穿透深度**（不是触及次数）」——在当前构造下，
那句话等价于「把止损距离画出来」。

各口径重算：

| 分组 | n | 均净R | **均净钱** | 均S(ATR) |
|---|---|---|---|---|
| 全部 | 1623 | −0.072 | −0.0088 | 0.121 |
| k = 1 | 199 | +0.039 | +0.0046 | 0.115 |
| k ≥ 2 | 1424 | −0.087 | −0.0107 | 0.122 |
| 深度递减 | 740 | −0.079 | −0.0083 | 0.116 |
| 深度未递减 | 684 | −0.097 | −0.0133 | 0.129 |
| 本次深度 = 0 | 853 | −0.117 | −0.0116 | **0.098** |
| 本次深度 > 0 | 770 | −0.023 | −0.0056 | **0.147** |

| 对比 | ΔR (t) | Δ钱 (t) | **ΔS(ATR)** |
|---|---|---|---|
| k=1 − k≥2 | +0.126 (+1.58) | +0.0153 (+1.85) | −0.007 |
| 递减 − 未递减 | +0.018 (+0.34) | +0.0050 (+0.86) | −0.012 |
| **深度>0 − 深度=0** | **+0.094 (+1.92)** | **+0.0060 (+1.08)** | **+0.049（止损大 50%）** |

**但要如实说：这一条不是致命。** 把止损距离切成 5 层、层内比较深度>0 vs 深度=0、
逆方差汇总，钱口径 Δ = **+0.0142 (z = +2.27)** ——**效应在控制之后没有消失，反而略强**。
所以「深度」不是止损距离的纯换名。问题是**报告没有做这个控制、没有披露这个共线性、
也没有给出钱列**，读者无从判断它读到的是哪一个。

另一条：§B.4 的「背离边际 Δ均净R 8/8 同号」也只有 R 列，而报告自己承认
「背离根的 N 根极值离收盘更近、止损更短」。同一个口径问题。

**可以直接引用的**：§A.5 的 200 次重抽安慰剂零分布，是本轮方法论质量最高的一段，
而且它立下的标准（「单次抽样的安慰剂没有证据价值」）恰好否掉了 §2.6 那份的安慰剂。

### 2.6 V15_NAMED_LEVEL_GATE —— 轻微（安慰剂），混淆维度上干净

**先说好的**：这一份在本轮的混淆问题上是干净的。它全程有净钱列（29 处），而且
d_min 与止损距离**本来就无关**——报告 §1 的相关矩阵里 d_A vs D4 = **−0.03**。
所以「贴位」这个变量不可能塌缩成止损距离，本轮的核心怀疑对它不适用。
§5 那个「K 横跨该位」的格子它也同时报了 z_sel(净R)=+2.14 与 z_sel(钱)=+1.45，
并自己指出那是 D2r 的重复测量。

**问题 1 · 安慰剂族是 9 条确定性梯 + 1 次随机相位抽样，且彼此不独立。**
报告自己的表里，平移 +0.25 与真梯 ρ = +0.499、等距相位 0 ρ = +0.553、
等距相位 0.10 ρ = −0.543。在这样一组 10 个点上估出来的
「均值 +0.08 / sd 1.62 / 真梯排第 4/10 / 经验分位 35%」，是从一个非 iid 的、n=10 的
样本里估出来的分布参数。

同一批的 `V15_LEVEL_RETEST_AND_DIVERGENCE.md` §A.5 刚刚用一个具体事故证明了这条：
同一份代码两次运行，单次安慰剂的 z_geom 从 +1.41 变成 −1.95，足以翻转结论；
它由此写下「本项目以后凡是做安慰剂对照，**必须重抽多次并报零分布**」。
本报告的等距梯完全可以按「每日随机相位」重抽 200 次（脚本里 `rng` 已经在了），
成本几乎为零。**在补做之前，那三个数字（sd 1.62、第 4/10、35%）不应被引用。**

**问题 2 · 安慰剂只替换 d_min，不替换 T1/S/结果。** 脚本 `build()` 第 283–295 行只给
每个信号多挂几个 `dS**/dE**/dER` 距离，交易本身（entry / prot / risk / t1）
仍来自真梯。这**对否定结论是保守的**（真梯的 d_min 与结果有机械纠缠，假梯没有，
所以真梯本该占便宜却没占到），但报告没有说明这一点，读者无法判断这个安慰剂公不公平。
补一句话即可。

**其余判决（闸门几乎是空的：91% / 97.5% 通过；三组趋势符号不一致；方向性反了；
286 格无一越 3.75；κ≈0 的跨标的不可移植）我全部复核过口径，成立，不需要改。**

## 4 · 给下一轮的三条口径规矩（本报告的唯一建议）

1. **凡是按风险距离（或与它相关系数 >0.3 的任何量）分层的表，必须同时报钱列。**
   R 的分母就是那个变量。本轮八份报告里有三份违反，其中两份的核心结论因此要撤回。
2. **凡是形如 y/x 对 x 的相关，零假设不是 ρ=0，是置换零分布。**
   ρ(|MAE|/S, S) = −0.505 的算术零分布是 −0.566。报 z 之前先报零分布。
3. **凡是安慰剂，必须重抽 ≥100 次并报零分布，且说明安慰剂替换了什么、没替换什么。**
   这条是 `V15_LEVEL_RETEST_AND_DIVERGENCE.md` §A.5 立的，本轮已经有一份报告
   （具名位闸门）在它立起来之前就写完了。
