## 一 · 算术分解：88% 是「笔数 × 每笔」

| | RTH | 夜盘 | 全部 |
|---|---|---|---|
| 信号数 | 142 | 375 | 517 |
| 笔数份额 | 27.5% | 72.5% | 100% |
| 均净R | -0.063 | -0.173 | -0.142 |
| 总净R | -8.9 | -64.7 | -73.6 |
| 总净R 份额 | 12.1% | **87.9%** | 100% |

亏损份额是一个乘积，不是一个现象：

```
夜盘亏损 / RTH亏损 = (笔数比) × (每笔亏损比)
                    = (375/142) × (0.173/0.063)
                    = 2.641 × 2.758 = 7.28
夜盘份额 = 7.28 / (1 + 7.28) = 87.9%
```

取对数把两个因子摊平：ln(7.28) = 1.986 = ln(2.641) + ln(2.758) = 0.971 + 1.014。
**笔数占 49%，每笔劣势占 51%——两个因子几乎五五开。**

### 1.1 反事实：如果夜盘每笔和 RTH 一样贵

| 情形 | 夜盘总净R | 全样本总净R | 夜盘份额 |
|---|---|---|---|
| 实际 | -64.7 | -73.6 | 87.9% |
| 夜盘每笔换成 RTH 的 -0.063 | -23.5 | -32.4 | 72.5% |
| 夜盘每笔归零（只剩 RTH 的亏） | 0.0 | -8.9 | 0.0% |

**答案：375 笔夜盘如果每笔只亏 RTH 那么多（-0.063），总净R 会从 -73.6 变成 -32.4，账本改善 +41.3R（56% 的亏损消失）。夜盘份额仍然有 72.5%——因为笔数还在那里。**

## 二 · 为什么夜盘每笔更差：尺度错配

假设：**目标是日线刻度，止损是结构刻度。** 目标 T1 = 顺方向下一个具名位，位阶梯的步长固定为日 ATR 的 0.236 / 0.146 / 0.118 …；止损是近几根 K 的极值，夜盘 K 小 → 止损小。于是夜盘的每一笔都变成「很远的目标 + 很紧的止损」。

### 2.2b 同样的 pp 缺口，夜盘要贵 1.2 倍

纯括号的期望 R 有一个闭式：命中 +T/S，止损 −1，而 T/S = (1−P)/P，所以

```
E[括号R] = p·(T/S) − (1−p) = (p − P) / P      （P = 几何零假设）
```

**在几何零假设上期望恰好为 0**（费用之前）。所以负 R 只能来自「实际命中低于零假设」，而同一个百分点缺口，在零假设越低的地方换算出的 R 越多——放大系数就是 1/P。

## 三 · 反事实

纪律 6：任何「砍掉笔数后总 R 转正」都必须先验证**单笔质量**是否真的提升。下面每一个反事实都报 Δ均净R、配对 t、以及有限总体修正的选择 z_sel。

### 3.1 夜盘强制最小风险距离 0.12 日ATR

两种做法，结论都要报：

- **(a) 事后筛选**：从已有的 375 个夜盘信号里挑出 S ≥ 0.12 ATR 的。这是「如果我当时知道就不做」的口径。

### 3.2 把目标改成「夜盘段已实现 ATR」的 0.236

这是检验尺度错配假设最直接的方式：**只换目标的刻度，其余一律不动**。

「夜盘段已实现 ATR」的构造与日线 ATR 完全平行——把每一段夜盘（16:00 收盘 → 次日 09:30 开盘，含周末的那一段一并算作一块）当作一根「K」，取段高/段低/段收，TR = max(H−L, |H−前段收|, |L−前段收|)，Wilder(14) 平滑，**取上一段收盘时的值**，所以段内任何一根 K 用它都没有前视。RTH 段同理。

## 四 · 与假设相反的格子（诚实优先）

- **夜盘里止损最宽的 20%**（S ≥ 0.170 ATR，n=75）：几何零假设 72.0%，命中 70.7%，超额 -1.4 pp (z=-0.28)，均净R +0.032，总净R +2.4。这一格与「夜盘全坏」直接冲突，也是 3.1 那个闸门唯一的依据。
- **RTH 本身也不赚钱**：均净R -0.063，总净R -8.9，z_geom +0.82（|z|<1.96，命中与几何零假设无法区分）。把「88% 的亏损在夜盘」读成「RTH 是好的」是错的——RTH 只是**曝光量小**（142 笔）且**每笔便宜**（止损宽 2.0 倍，点差摊薄），它的超额 +3.0 pp 在 n=142 上完全够不着显著。

## 五 · 多重比较

全文共检视 **94 个格子**（分层格、时段格、逐小时格、闸门、反事实口径）。Bonferroni 门槛 |z| > **3.46**（α=0.05 双侧）。

| 关键 z | 值 | 过 1.96？ | 过 Bonferroni？ |
|---|---|---|---|
| 夜盘 z_geom（纯括号 vs 几何零假设） | -2.68 | 是 | 否 |
| RTH z_geom | +0.82 | 否 | 否 |
| 全样本 z_geom | -1.88 | 否 | 否 |
| 夜盘 vs RTH 信号密度 两比例 z | +0.53 | 否 | 否 |
| 夜盘均净R 的 t | -4.05 | 是 | 是 |
| RTH 均净R 的 t | -1.31 | 否 | 否 |
| S/ATR ↔ 几何零假设 秩相关 z | +14.40 | 是 | 是 |

**没有一个跨过 Bonferroni 门槛。** 但注意：本文的主张不是「某个格子显著」，而是**一组恒等式**——笔数份额 = K 数份额、止损比 = K 振幅比、点差比 = 调和均值倒数比、E[括号R] = 超额/零假设。这些是算术，不需要显著性；需要显著性的只有「超额 ≠ 0」这一条，而它（z=-2.68）恰恰是本文最弱的一环，必须如实标注。

## 六 · 一句话回答

> **夜盘扛下 88% 的亏损，是「49% 平凡 + 51% 真实缺陷」的乘积：平凡的那一半是夜盘本来就占了 72% 的 K（信号密度只有 RTH 的 1.05 倍，两比例 z=+0.53，没有额外的过度交易）；真实缺陷的那一半是**尺度错配**——止损跟着夜盘 K 缩到 RTH 的 49%，目标却仍按日 ATR 阶梯走，于是几何零假设从 66.7% 塌到 54.3%，每 1 pp 的命中缺口被放大成 1.84R（RTH 只有 1.50R），同时 0.6 点的固定点差摊在小 1.7 倍的 R 上变贵一倍。**

拆成可执行的三句：

1. **平凡**（不用修）：73% 的笔数份额 ≈ 72% 的 K 数份额 ≈ 16.5/23 小时。夜盘没有过度交易。
2. **真实缺陷 · 主因**（尺度错配）：目标是日线刻度、止损是结构刻度。夜盘 T/S 中位 0.88R vs RTH 0.43R。把目标换成夜盘段刻度后，z_geom 从 -1.87 变成 -2.93，均括号R 从 -0.155 变成 -0.320。
3. **真实缺陷 · 次因**（点差）：占每笔劣势的 32%，且 100% 由「R 更小」解释，不是独立成分。
