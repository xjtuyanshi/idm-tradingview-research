# V15 · 日线偏向层：有没有信息，如果有，正确的用法是什么

生成脚本 `research/satylab/study_bias_layer.py`。

## 0 · 这一轮在回答什么

用户已经否掉了把日线偏向当**硬闸门**：

> 「日内交易不可能一直都是单边下跌的……位置下不去以后最终不还是反抽上来了吗」

但同一段对话里他也说：

> 「第一层那个确实是有用的，我认为是给一个 bias 的参考」／「你也可以去研究一下它的历史」

所以问题不是「能不能当闸门」（已否），而是：**偏向到底有没有信息；如果有，既然不能筛信号，正确的用法是什么。**

## 1 · 偏向定义、样本、以及一个必须先说的混淆

### 1.1 四个定义（全部只用前一根已完成日线及更早，盘前即固定）

| 记号 | 定义 | 取值 |
|---|---|---|
| D-EMA21 | 前一日收盘 vs 日线 EMA21 | ±1 |
| D-Ribbon | 日线 EMA 8/13/21/34/48 是否完全排列 | +1 多排 / −1 空排 / 0 缠绕 |
| M-Pivot | 前一日收盘 vs 上一个**已完成**月的 pivot (H+L+C)/3 | ±1 |
| W-EMA21 | 前一日收盘 vs 周线 EMA21（只用**已完成**周） | ±1 |

周线 EMA21 刻意只用已完成周、月 pivot 刻意只用已完成月——TradingView 上习惯用「还在长的当周/当月」，那在回测里是前视。这里宁可让指标钝一点。

**这张表要小心读，两个坑：**

1. **几何差只出现在两种定义上。** 风险距离的 Δ 在 D-EMA21（z −4.47）和 M-Pivot（z −3.40）上很大，在 D-Ribbon（z −0.06）和 W-EMA21（z +0.20）上**完全没有**。合理解释：D-EMA21 / M-Pivot 是「前收 vs 一条价格常在附近来回穿的线」，「逆偏向」在这两种定义下意味着价格已经越过那条线并走远，结构止损自然更远；而 D-Ribbon 把模棱两可的日子丢进「中性」档（467 天里 114 天），W-EMA21 则几乎恒为多（406 : 61），顺/逆退化回多/空。所以这是**两个定义**的性质，不是「偏向」这个概念的普遍性质。
2. **「均钱」四种定义全部没有差别**（|z| ≤ 1.36）。也就是说：顺偏向和逆偏向，按固定金额风险下单时赚到/亏掉的钱是一样的。**没有任何证据支持按偏向调整仓位倍数。**

**混淆核对**：顺偏向里 70% 是多单、逆偏向里 33% 是多单，而 S2 里多单的均风险距离本来就比空单大。如果 Δ风险距离 只是这个组成差造成的，那应该是顺偏向的风险**更大**才对：

- 多单均风险 0.388 ATR，空单 0.343 ATR。

## 4 · 持续性检验：「反抽」到底多常见

直接回应这句：

> 「日内交易不可能一直都是单边下跌的……位置下不去以后最终不还是反抽上来了吗」

度量：当日（含夜盘，trade_day 口径）**最低点之后**的最高价，减去最低点，除以当日 ATR（前一日 Wilder ATR14）。这是「跌完之后反抽了多少」的直接量化。镜像量是最高点之后的最低价。样本 = ES=F 1h 730d 的每个交易日。

⚠ 这个度量有一个内建的选择偏差，必须先说：**从当日最低点起算的反弹一定 ≥0**，因为最低点就是全天最有利的起跳点。所以「87% 的日子反弹 ≥0.236 ATR」**不是一个可交易的数字**——没有人能买在最低点。它能回答的是另一个问题：**「当天有没有过一段像样的反向行情」**，也就是硬闸门会不会挡掉真实存在的机会。跨组比较（偏空日 vs 偏多日）是公平的，因为同一个选择偏差对两组一样。

## 9 · 局限

1. **位价局限（纪律 5）**：主样本 ES=F，作息与 CAPITALCOM:SPX500 一致。^GSPC 只在 §6 做方向性对照。ES=F 与 SPX500 的 ATR 比值不是常数（246 天 mean 1.117 / sd 0.083 / 范围 0.826–1.418），所以本报告里所有依赖具体位价的数字（月线 pivot、±0.382 ATR 括号）在用户实际交易的标的上会有几个百分点的偏移；结论是关于**方向与幅度的秩序**，不是关于具体价位。
2. **S1 的偏向不翻**：60 天窗口里日线偏向几乎恒为多，「顺/逆」与「多/空」几乎共线，S1 的任何顺/逆差都不能解读为偏向的作用。
3. **S2 换了 setup 周期**：主证据来自 1h setup K，而生产是 10m。命中率、几何零假设、风险距离的**绝对值**在两个周期上不可比（S1 命中 54%、S2 命中 71%，就是周期差出来的）。可比的只有**同一样本内部顺/逆两组的差**。任何把 S2 的绝对数字搬到生产周期上的读法都是错的。
4. **S2 的路径分辨率**：1h 没有更细的数据，同一根 K 内两侧都被触到的交易一律记未裁决（纪律 3）。未裁决率在表里逐格报出；如果两组未裁决率差很多，命中率的对比本身就有选择偏差。
5. **日聚类**：所有关键 z 都按交易日聚类。朴素 z 一律不作数。
6. **样本量**：S1 约 50 个交易日、S2 约 600 个交易日。S2 的 600 天里日线偏向的**独立**翻转次数远少于 600——偏向本身是高度自相关的序列，日聚类也修不了这一层。真正的有效样本是「偏向段」的数目，量级在两位数。任何 S2 上的边际显著都要按这个折价。

## 10 · 判决

### 10.1 偏向有没有【方向】信息？没有。

- **S2（1024 笔 / 467 天，偏向会翻）**：四种定义、顺/逆两组，扣掉几何零假设之后的超额全部落在 -1.1 pp 到 -0.3 pp 之间，日聚类 z 最大 |z| = 1.58。没有一项接近 1.96，更不用说 Bonferroni 门槛 3.65。
- **S3（ES=F 日线 4929 根 / 20 年）**：偏多组收涨 54.1%、偏空组收涨 54.7%，无条件收涨率 54.3%——**偏空日的次日收涨率反而略高于偏多日**。^GSPC 上同一张表同一个方向（偏空 55.8% vs 偏多 53.7%）。
- **对称括号赛跑（几何零假设正好 50%，没有几何可藏）**：偏多日先触上方 51.8%，偏空日先触上方 53.8%。两个都在 50% 附近，而且**排序是反的**。

这与既有结论一致，不构成冲突：**方向不可由 ribbon / phase / 跳空方向 / 首小时方向 / 位状态预测**，现在再加一条——也不可由日线偏向预测。这一轮没有发现任何需要「极高标准证据」的反常结果。

### 10.2 那它有没有信息？有，在【幅度】和【几何】上。

S2 里顺/逆两组最稳的差别根本不是命中率，而是**交易的几何形状**：

| | 顺偏向 | 逆偏向 | 差 |
|---|---|---|---|
| 几何零假设（=S/(S+T)） | 68.1% | 75.8% | -7.7 pp |
| 均风险距离(ATR) | 0.317 | 0.410 | -0.093 |
| 均T1距离(ATR) | 0.111 | 0.102 | +0.009 |
| 赢单均净R | +0.684 | +0.447 | +0.237 |
| 输单均净R | -0.510 | -0.372 | -0.137 |
| 均净R | -0.106 | -0.099 | -0.007 |

读法：**顺偏向的交易是「大赢大输」，逆偏向的交易是「小赢小输」**，而两者的期望几乎一模一样（−0.106 vs −0.099），换算成钱（净R × 风险距离）更是完全重合（−0.0245 vs −0.0234，z_clu −0.10）。§3.3 的分解把这件事量化到底：D-EMA21 的 Δ均净R 里，命中率贡献只占 2%，幅度贡献占 98%；M-Pivot 是 5% / 95%。四种定义里命中率贡献占比最高的 W-EMA21 也只有 40%。

**所以偏向是一个尺度（scale）信号，不是一个方向（sign）信号。**但要立刻加上 §3.2 的两个限定：这个尺度效应只在 D-EMA21 和 M-Pivot 上显著（D-Ribbon、W-EMA21 的 Δ风险距离 |z| < 0.21），而且它**不转化为钱**——它改变的是同一笔钱被切成 R 的方式，不是钱本身。

### 10.3 正确的用法（严格区分「数据支持的」和「数据没反对但也没检验的」）

| 用法 | 判定 | 证据 |
|---|---|---|
| 硬闸门（逆偏向不许开仓） | **数据反对** | 逆偏向的期望和顺偏向一样（Δ均净R -0.007，z_clu −0.16；Δ钱 −0.001，z_clu −0.10）。砍掉一半笔数换不来单笔质量提升，只是把样本砍半（纪律 6）。而且 §4 显示偏空日里 82% 都出现 ≥0.382 ATR 的反抽。 |
| 按偏向调仓位倍数 | **数据反对** | 「均钱」四种定义全部无差别（z 绝对值 ≤ 1.36）。顺/逆的风险距离确实不同，但按固定金额风险下单时这一步已经自动完成，**再乘一个偏向系数没有任何证据支持**。 |
| 按偏向调目标 / 分批点 | **未检验，别当成结论** | 数据只说明「逆偏向的 T1 天然更近」（顺 0.111 vs 逆 0.102 ATR，四种定义同号，最大 z 2.54，未过 Bonferroni）。「所以顺偏向该把 T2 放远」是**推论，本报告没有检验它**——要检验必须重跑一遍带不同目标规则的完整回测。别把它写进结论。 |
| 显示 / 账本分组 | **数据不反对，且成本为零** | 偏向不改变任何一笔的期望，所以拿它当解释语言和复盘维度是安全的：它不会让你少做或多做任何一笔。这正是 v15 已经采纳的位置。 |

**一句话**：用户的直觉「第一层是给一个 bias 的参考」在数据上成立，但成立的方式比他说的还要弱一点——偏向连「参考」的方向性都没有，它只描述**今天这笔交易会长成什么形状**（止损多远、目标多近、赢单输单的尺寸），不描述**它会不会赢**。

### 10.4 与状态层的交互：先验猜测不成立

任务书的先验是「趋势态里偏向有用、区间态里偏向有害」。数据不支持：

- ER10 三分位 × 4 定义：**趋势态（ER 高）那一档里，顺偏向的均净R 反而更低**（D-EMA21 Δ −0.141，z −2.02；D-Ribbon Δ −0.177，z −2.24），符号与先验相反。
- 月线位状态 × 4 定义：`extended` 那一档四个定义齐刷刷 Δ超额 +10 到 +14 pp，看着最像真的——但 n 只有 47–89，|z| 只有 1.14–1.30，而且四个定义在这一档高度重叠（D-EMA21 和 M-Pivot 的格子 n 完全相同：73/89），不是四个独立证据，是同一批日子被数了四遍。

28 个交互格（Δ超额口径）里最大 |z| = **1.30**（月线·extended·D-Ribbon Δ超额），Bonferroni 门槛 3.65。**没有交互。**

### 10.5 用户那句话的量化答案

> 「日内交易不可能一直都是单边下跌的……位置下不去以后最终不还是反抽上来了吗」

**对，而且偏空日反抽得比偏多日还大。** ES=F 603 个交易日（1h 路径，5m 复核在 §4）：

- 日线偏空的 168 天里，日内低点之后反弹 ≥0.236 ATR 的占 88%，≥0.382 占 82%，≥0.618 占 71%，反弹中位 0.884 ATR。
- 偏多的 435 天里同样口径是 86% / 74% / 48%，中位 0.604 ATR。
- 即使只看**真的收阴**的 263 天，低点后仍有 72% 反弹 ≥0.236 ATR。
- 日内低点的中位出现位置是当日进程的 68%——反抽不是收盘前才发生的，后面还有三分之一个交易日。
- **尺寸对比**：偏空日的中位「开盘→低点」跌幅是 0.418 ATR，中位「低点后反弹」是 0.884 ATR，比值 2.02；72% 的偏空日里**反弹幅度大于当日跌幅**。

这就是硬闸门在机制上错在哪里：闸门的隐含假设是「偏空日 = 单边下跌日」，而数据说偏空日的**反抽幅度比偏多日更大**（中位 0.884 vs 0.604 ATR）。偏空日之所以反抽更大，只是因为它们的绝对波动更大——这又一次是**幅度**，不是**方向**。
