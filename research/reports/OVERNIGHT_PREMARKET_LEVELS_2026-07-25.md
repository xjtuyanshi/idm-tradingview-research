# 夜盘 / 盘前位研究（2026-07-25）

> 脚本：`research/satylab/study_overnight.py`、`study_overnight_robust.py`
> 数据：**ES 期货**（近 24 小时交易，730 天，595 个完整交易日）。
> 为什么必须换标的：SPX 现货（^GSPC）根本没有夜盘，Saty 满嘴的
> "pre-market support / overnight lows" 在现货数据上**无法定义**，
> 之前所有研究都绕开了这块。ES 也正是 CAPITALCOM:SPX500 CFD 夜盘所跟踪的东西。

## 0. 为什么做这个

`docs/SATY_PLAYBOOK_CORPUS.md` 逐字抄了 Saty 九篇盘前帖。统计他实际点名的位类型，
出现频率最高的三个我们**一个都没有**：盘前高低、夜盘高低、H21(RTH)。
本研究先攻前两个。**注意：我没有做参数搜索——只把他原话里点名的 5 件事各测一遍，
全文共 14 个统计格子。**

## 1. 五张基准率表（ES，n=595 个交易日）

**① RTH 是否扫掉夜盘区间**
| | 比例 [95% CI] | n |
|---|---:|---:|
| 扫掉夜盘高 | 57.8% [53.8, 61.7] | 595 |
| 扫掉夜盘低 | 47.2% [43.2, 51.2] | 595 |
| 两边都扫 | 12.6% [10.2, 15.5] | 595 |
| 两边都没扫（困在夜盘区间内） | 7.6% [5.7, 10.0] | 595 |

**夜盘区间是真边界**：只有 7.6% 的日子整天被关在里面，说明它几乎总会被测试；
而两边都扫只有 12.6%，说明**扫掉一边之后通常不回头**。

**② 先扫哪一边 → 当日收盘方向**
| | 比例 [CI] | n |
|---|---:|---:|
| 先破夜盘高 → 收阳 | 74.6% [69.4, 79.2] | 303 |
| 先破夜盘低 → 收阴 | 70.0% [64.1, 75.4] | 247 |

**是延续，不是反转。** （诚实标注：这一项与结果部分同义——先破高的日子本就偏强，
所以数字被高估。它适合放进概率地图，不适合当作独立 alpha。）

**③ 夜盘区间大小 → 当日是否触及 ±1 ATR**
| 夜盘区间/日ATR | 触及 ±1 ATR | n |
|---|---:|---:|
| 窄 <0.4 | **2.6%** [1.0, 6.6] | 151 |
| 中 0.4–0.8 | 16.7% [12.9, 21.3] | 300 |
| 宽 >0.8 | **56.2%** [48.1, 64.1] | 144 |

单调、跨度巨大（2.6% → 56.2%）。**这是"今天值不值得做大目标"的免费过滤器**，
开盘前就能知道。（部分机械性：夜盘宽本身就是高波动日的表现。）

**④ 夜盘位置 → 当日完成 Golden Gate**
| 夜盘最高到哪 | 当日完成 GG(0.618) | n |
|---|---:|---:|
| 未过 0.236 | **5.6%** [3.4, 9.0] | 268 |
| 只到 0.236 | 22.1% [15.5, 30.6] | 113 |
| 已到 0.382 上方 | **64.0%** [57.4, 70.1] | 214 |

这解释了 Saty 那句 "**Possible GG open if we open here or above**"——
他是在用基准率下注。（部分机械性：夜盘已到 0.382 意味着只差 0.236 ATR。）

**⑤ Saty 剧本原句的直接检验** ← 本研究的核心

条件复刻自他的原话："**If we continue to hold pre-market support and break trend
back over pre-market highs, we can head toward [下一个位]**"

| | 触及上方下一个具名位 | n |
|---|---:|---:|
| 守住盘前低 + 上破盘前高 | **80.3%** [75.3, 84.5] | 289 |
| 未守盘前低就上破盘前高 | 59.8% [49.3, 69.4] | 87 |
| | **z = +3.90** | |

## 2. 稳健性拷问（这一节比上面重要）

对第⑤项跑了四重攻击：

**A 同义反复 — 通过。** 两组前提相同（都上破了盘前高），差别只在此前路径；
目标位来自与盘前区间无关的日线 ATR 位图；结果发生在条件确定之后。

**B 混杂 — 部分失败，且失败得很有信息量。**

| 控制变量 | 效应是否存活 |
|---|---|
| 开盘跳空 | 3 档中 2 档存活（z=2.46 / 2.42），小跳空档消失（z=1.40） |
| 夜盘区间大小 | 3 档中 2 档存活（z=2.46 / 2.65），大区间档消失（z=1.12） |
| 到下一位的距离 | 两档均存活（z=2.89 / 2.49）✓ 最稳 |
| **破位时剩余时间** | **两档均消失（z=0.91 / 1.33）** ← 关键 |

**控制住"还剩多少时间"之后，效应从 +20.5pp 缩到约 +9pp 并失去显著性。**
也就是说：**"守住盘前支撑"有相当一部分只是"更早突破"的影子**。

**C 时间稳定性 — 通过。** 三段同号：z=+2.21 / +1.15 / +3.45。

**D 换标的 — 无法进行。** Yahoo 的 SPY 小时线不含盘前，无法定义条件。
待用 TradingView 导出 CAPITALCOM:SPX500 补验。

## 3. 真正的结论：主导变量是"多早"

把两个变量放进同一张交叉表（n=376）：

| | **早破**（10:30 前） | **晚破** |
|---|---:|---:|
| **守住盘前低** | **80.9%** (n=257) | 75.0% (n=32) |
| **未守盘前低** | 72.1% (n=43) | **47.7%** (n=44) |

- 单独效力几乎相等：守住 +20.5pp（z=3.90）／早破 +20.5pp（z=3.71）
- **但两者是替代关系不是叠加关系**：有其一就有 72–81%，两个都没有才掉到 47.7%（掷硬币）
- **可执行的规则不是"找信号"，而是"避开一个格子"**：
  **已经跌破盘前支撑、又拖到 10:30 之后才突破的，不做。**

## 4. 与 Golden Gate 研究的会合

这是本周末最重要的一条：**两个完全独立的研究指向同一个变量。**

- GG 完成率按触发时刻衰减：开盘 89.7% → 09:30 70.8% → 13:30 29.2% → 15:30 0%
- 盘前突破按剩余时间衰减：剩 5–6 根 79.7% → 剩 3–4 根 67.3% → 剩 <3 根 44.4%（z=3.71）

**同一个机制，两次独立测到**：日内延续的主导变量是**行情启动得多早**，
而不是任何一个形态或指标。三条原因（时间预算、日内波动 U 型、以及最关键的
选择效应——早启动本身就是趋势日的证据）已在 GG 报告 §"为什么越往后越低"展开。

**对系统设计的直接含义**：时段过滤不是可选项，是主变量。
旧系统把 09:30–14:00 当作一条普通规则，实际上它应该是**概率表的第一个索引维度**。

## 5. 诚实边界

1. 以上全是**触及某位的条件概率**，不是交易盈亏。GG 研究已证明高触及率可以配上
   糟糕的交易几何（赢单最深回撤 0.303 ATR > 报酬 0.236 ATR）。**这些数字进面板，不进下单。**
2. 第②③④项含机械成分（条件与结果部分同源），已逐条标注。第⑤项经过四重攻击，
   但真实效应量应按控制时间后的 **+9pp** 理解，而非头条的 +20.5pp。
3. ES ≠ CAPITALCOM:SPX500。基差、结算时点、CFD 的日界都可能不同，
   **必须用 TV 导出的 CFD 数据复验**（列入待办）。
4. 730 天覆盖 2024-03 至 2026-07，只含一种宏观环境。
